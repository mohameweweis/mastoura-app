تحديث الواجهة الاحترافية - نظام إدارة العاملين والمعدات

تم تطوير الواجهة لتصبح RTL وبهوية احترافية قريبة من التصميم المرجعي، وتشمل:
- لوحة تحكم حديثة مع بطاقات إحصائية وتنبيهات وأحدث العاملين والفروع.
- قائمة جانبية ثابتة لجميع وحدات النظام.
- شاشة عاملين ببحث وتصفية حسب الفرع.
- نافذة لإضافة عامل مرتبطة بالـ API الحالي.
- ملف عامل جانبي يعرض البيانات الأساسية وملخص الدورات والكروت والقيادة عند توفرها.
- صفحات مبدئية منظمة للدورات والكروت والسائقين والمعدات والفحوصات والفروع والتقارير والصلاحيات والإعدادات.
- تصميم متجاوب للكمبيوتر والتابلت والجوال.
- لا توجد مكتبات واجهة إضافية مطلوبة؛ تم استخدام SVG icons محلية لتقليل الاعتماديات.

التشغيل:
1) افتح المجلد في الطرفية.
2) npm install
3) npm run dev

مهم:
الواجهة تعتمد على الـ API الحالي على:
http://localhost:3000/api

التصميم جاهز للتوسعة وربط بقية الوحدات عندما تكتمل API الخاصة بها.
